# millennium-hq

millennium is a plugin for AI coding agents, Claude Code first, that makes
quality and security the default outcome of agent-driven development. Rules
that can be checked mechanically are enforced by a gate engine the agents
cannot talk their way past; the judgement calls go to fresh-context reviewers
whose findings a tech lead must explicitly dispose of.

Status: early development. The gate engine works today as a command-line
tool; the Claude Code plugin around it is being built.
